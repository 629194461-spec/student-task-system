# 学习星球

面向小学生、家长和平台管理员的学习任务管理系统。服务端使用 Node.js 24 内置 SQLite，前端与 API 同源部署。

## 本地启动

```bash
npm start
```

访问 `http://127.0.0.1:4173`。系统不会初始化演示学生、家长或任务；首次启动只创建内置超级管理员：

| 账号 | 密码 | 用途 |
| --- | --- | --- |
| `admin` | `admin@2026` | 内置超级管理员，可管理全部家长和学生 |

## 生产部署

1. 复制 `.env.example` 为 `.env`。首次部署后使用内置超级管理员登录。
2. 使用 HTTPS 反向代理，将应用暴露到公网；生产 Cookie 会自动设置 `Secure`、`HttpOnly` 和 `SameSite=Strict`。
3. 运行 `docker compose up -d --build`。数据库持久化在 `learning-planet-data` 卷中，应纳入备份计划。

单实例部署可以直接使用内置 SQLite/WAL。多实例或高并发生产环境应将数据库层替换为托管 PostgreSQL，并将内存登录限流替换为 Redis。

## 已实现安全机制

- 用户名、密码和角色的服务端校验，密码使用 `scrypt` 加盐哈希。
- 服务端生成的短时图形验证码，一次使用后立即失效。
- 每个来源 IP 在 15 分钟内最多 8 次失败登录尝试。
- HttpOnly、SameSite=Strict 会话 Cookie；普通会话 12 小时，电脑浏览器可申请 30 天免登。
- 学生端 API 只按会话中的学生 ID 查询数据；普通家长端按关联关系隔离学生、审核和统计数据。
- 家长账号管理和学生重新关联接口仅允许超级管理员调用；家长解绑后无法自行恢复关联。
- 任务分类菜单及写接口仅超级管理员可用；普通家长只能在任务和模板表单中使用已有分类。
- 任务模板支持开放或私有可见性，用户只能修改、删除本人创建的模板。
- 学生和家长任务详情使用只读接口，查看详情不会触发开始任务、反馈提交或审核操作。
- 家长与学生共用全局唯一用户名；账号创建后用户名只读，不允许通过编辑接口修改。
- 常见响应安全头、路径校验、文件签名校验、请求体大小限制与参数长度限制。

完整生产部署、备份恢复和运维说明见 [`前后端部署说明.md`](./前后端部署说明.md)。
